# Text2Html

A Django web application that converts plain text into HTML.

## How it works

Paste or submit plain text through the web interface, and the app converts it into corresponding HTML markup that you can copy and use.

## Getting started

```bash
python manage.py migrate
python manage.py runserver
```

Then open the app in your browser to convert text to HTML.

## Tech stack

- Python / Django
- SQLite (development database)
